# Music Junkie — Mobile Mockups

Source files for the 10 mobile mockup screens (dark theme, light-blue accent #5CC8FF, Figtree type).

The live, clickable version is the Music Junkie — Mobile Mockups canvas:
https://claude.ai/artifact/N9mJs5CSxWUDCyXrbCk3fb

These `.dc.html` files need the canvas runtime to render, so they won't display correctly if opened directly in a browser. To get images or a PDF of the screens, open the canvas and use Share › Export.
